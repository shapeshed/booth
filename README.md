# Booth

Just podcasts for Android.

## Install

Signed APKs are available from the
[GitHub Releases](https://github.com/shapeshed/booth/releases) page. Booth is distributed outside
Google Play; verify the checksum published with each release before installing.

## Features

- Follow your favourite podcasts, including OPML import.
- Find podcasts and search episodes quickly.
- Keep subscriptions up to date automatically.
- Play, queue, download, and resume episodes with media controls.
- Listen offline and set a sleep timer.
- Keep listening privately with no accounts, advertising, analytics, or tracking.

Booth does not include advertising, analytics, tracking SDKs, Firebase, mandatory accounts, or a
